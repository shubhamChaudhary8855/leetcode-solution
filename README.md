## 💡 My Problem-Solving Approach

For each problem, I aim to follow this process:

```text
Understand the Problem
        ↓
Identify Constraints
        ↓
Think of a Brute-Force Approach
        ↓
Optimize the Approach
        ↓
Write Clean Code
        ↓
Analyze Time & Space Complexity
        ↓
Test Edge Cases
```

The goal is not simply to collect solved problems, but to understand **why a solution works and how it can be improved**.
